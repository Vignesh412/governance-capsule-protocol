# Security Policy

## Project status

This repository contains experimental research code. It has not completed a security review and must not be treated as a production authorization or compliance system.

## Reporting

Until a private reporting channel is published, do not include operational secrets, personal data, or exploitable production details in a public issue. Open a minimal issue requesting a private contact path, or contact the repository owner through their GitHub profile.

## Supported versions

There are no supported production versions yet. Security fixes will target the current development branch.

## Security boundaries

The reference implementation can verify cryptographic assertions and modeled transformation rules. It does not prove that a signed assertion is truthful, that an enforcement runtime executed what it claimed, or that application-specific policy is legally sufficient.
